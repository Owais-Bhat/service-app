# Landing Ads - Banner Size Specifications

## Required Resolution For Landing Ads

### Desktop Banner
**1920px × 450px**
- Full-width responsive banner
- Shows on desktop/tablet (768px and wider)
- Landscape orientation

### Mobile Banner  
**1920px × 450px**
- Responsive scaling (100% width)
- Shows on mobile devices (under 768px)
- Same aspect ratio as desktop (4.27:1)

---

## Admin Form Configuration

When uploading ads, set:

1. **Slide type**: Image or Video
2. **Media Source**: Upload your image file
3. **Caption**: Optional text overlay
4. **Duration**: How long to display (6 seconds recommended)
5. **Position**: Order in carousel (1, 2, 3, etc.)
6. **Device Target**: 
   - `desktop` - Show on desktop only
   - `mobile` - Show on mobile only
   - `both` - Show on all devices
7. **Active**: Check to enable the ad

---

## Image Specifications

| Spec | Details |
|------|---------|
| **Format** | JPG, PNG, or WebP |
| **Resolution** | 1920 × 450 pixels |
| **Aspect Ratio** | 4.27:1 (landscape) |
| **File Size** | Under 300KB recommended |
| **Color Space** | RGB or sRGB |

---

## Desktop vs Mobile

**Desktop Image:**
- Optimized for landscape viewing
- Shows on computers/tablets (768px+)
- Set Device Target to `desktop`

**Mobile Image:**
- Optimized for mobile screens  
- Shows on phones (<768px)
- Set Device Target to `mobile`

---

## Don't Show

- Desktop images do NOT appear on mobile
- Mobile images do NOT appear on desktop
- Only images with matching Device Target will show
